# 快速開始

把 AI 資安長治理閘道跑起來，並插到你的 agent 上。約 10 分鐘。

## 你需要先有

- **Docker Desktop**（或 Docker + Compose v2）——先裝好、確定有在跑
- **一個模型端點**，三選一：
  - 區網 / 本機 **Ollama**：一個網址（例：`http://192.168.47.77:11434`）+ 模型名（例：`gpt-oss:120b`）
  - **OpenAI 金鑰**（`sk-...`）
  - Nous / xAI 登入
- **你的 agent**：Hermes（先裝好），或任何 OpenAI 相容的用戶端（Cursor、Aider、LangChain、用 OpenAI SDK 的程式…）
- 第一次啟動需要**能連網**（拉 Docker 映像檔）

---

## 步驟

### 1. 解壓、進目錄

```bash
tar -xzf dciso-gateway.tgz
cd dciso-governance-gateway
```

### 2. 產生設定

```bash
./bin/dciso setup
```

這會從 `.env.example` 建立 `.env`，並在你這台機器上產生 `GATEWAY_MASTER_KEY`
（你的 agent 唯一要拿的 token）和其他機密。這些只存在你本機。

### 3. 填入你的模型端點

編輯 `.env`，改這一行（用你的 Ollama 網址）：

```
OLLAMA_BASE_URL=http://192.168.47.77:11434
```

（用 OpenAI 的話：把 `OPENAI_API_KEY=` 那行填上你的金鑰，步驟 4 改用
`./bin/dciso demo`。）

### 4. 啟動治理閘道

```bash
OLLAMA_BASE_URL=$(grep ^OLLAMA_BASE_URL .env | cut -d= -f2) \
  ./bin/dciso up-ollama gpt-oss:120b --ciso rule --agent generic
```

- `--ciso rule`：資安長用快速的規則引擎（秒回）。
- `--agent generic`：治理任何 OpenAI 相容用戶端，不只 Hermes。

等到看到 `stack up`。確認：

```bash
./bin/dciso status
```

### 5. 插入你的 agent

**如果你用 Hermes：**

```bash
./bin/dciso plug --clone
```

這會治理你 `~/.hermes` 的一份**設定複本**（`~/.hermes-governed`），原本的完全不動。
然後在**另一個終端機視窗**：

```bash
export HERMES_HOME=~/.hermes-governed
hermes
```

**如果你用其他 agent（Cursor / Aider / LangChain / OpenAI SDK…）：**

在那個 agent 的設定裡：

- Base URL / `OPENAI_BASE_URL` → `http://127.0.0.1:4000/v1`
- API key / `OPENAI_API_KEY` → `.env` 裡的 `GATEWAY_MASTER_KEY` 的值
- **移除**原本的 provider 金鑰

就這樣，沒有要裝任何外掛。

### 6. 打開治理看板

```
http://127.0.0.1:8900
```

（Linux：`xdg-open http://127.0.0.1:8900`）

每一個被治理的決策都會出現在這裡：放行 / 擋下 / 遮蔽 / 送審，以及是哪條政策、
耗時多少。

---

## 驗證它真的在治理

叫你的 agent 做一件危險的事，例如：

> 讀 `~/.ssh` 資料夾裡的私鑰

應該被擋下，agent 收到一句「無法完成…」，看板出現一列 **DENY**。

---

## 停止 / 拔除

```bash
./bin/dciso unplug --clone     # 還原 Hermes 設定（其他 agent：把 base_url / api key 改回去）
./bin/dciso down               # 停止閘道（保留稽核紀錄）
```

---

## 遇到問題

```bash
./bin/dciso doctor             # 檢查 Docker、.env、各服務
./bin/dciso logs gateway       # 看閘道 log
./bin/dciso down               # 全部停掉重來
```

- 每個請求都被擋、理由是「安全檢查服務不可用」→ 你可能選了 `--ciso hermes` 但沒有
  設好 Ollama；改用 `--ciso rule` 重啟。
- Hermes 說連不到模型 / 掉回 OpenRouter → 重跑 `./bin/dciso plug --clone`。

更完整的說明看 `docs/SOP-架設.md`；想逐項展示功能看 `docs/DEMO-runbook.md`。
